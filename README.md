## 先弄明白：Claude Code 收的到底是什么钱

Claude Code 是跑在终端里的编程 agent，工具本身不要钱，你付的是背后模型的算力。这一点决定了套餐设计的逻辑——不是「解锁功能」，而是「给你多少额度」。

有一个容易踩的坑：**Claude 的免费版不含 Claude Code**。想用它，最低门槛是 Pro。所以「免费能不能用 Claude Code」这个问题，答案是不能。

从付费路径看，实际上只有三条：

1. **官方订阅**（Pro / Max / Team / Enterprise）：固定月费，额度按时间窗口重置，超了就是等或者升级。
2. **API 按量计费**（Console 账号）：插上 API Key 用多少扣多少，没有窗口限制，但账单没有上限。
3. **第三方代订**：你自己有 Claude 账号，由第三方平台帮你完成付款和订阅，比如 WildAI（bewild.ai）这类服务。

第二条路对写自动化脚本、跑 CI 的人更合适，因为没有窗口限制；但如果你只是每天坐在终端里和它结对写代码，第一条路更省心，账单也更好预测。第三条路存在的原因只有一个——支付通道。

### 5 小时窗口和周限额，才是选档位的真正依据

看价格表容易误判，因为订阅制的额度不是「一个月多少 token」，而是两层限制叠在一起：

- **5 小时滚动窗口**：从你发出第一条消息开始算，窗口内的用量累计封顶。窗口重置后可以继续。
- **周限额**：在 5 小时窗口之上，还有一层以 7 天为周期的总量限制，覆盖所有模型。

关键在于，Claude Code 统计的是「模型实际处理时间」，不是墙上时钟。你在读代码、想需求、敲键盘的间隙不算消耗，所以一个 5 小时窗口实际能覆盖的工作时长可能远超 5 小时。

这也意味着：**如果你习惯开一个 agent 然后走开让它自己跑，烧额度会快得多**。同样的钱，交互式使用的人撑一周，挂后台跑 agent 的人可能两天就触顶。

所以选档位的判断标准不该是「我一天写几小时代码」，而是：

- 你是不是长时间连续对话（窗口按处理时间算，对你有利）
- 你会不会同时开多个会话或跑子 agent（token 消耗按倍数上去）
- 你能不能在触顶时接受切到更小的模型继续干活

Pro 的额度对「每天认真用两三个小时」的人通常够用。真正会撞墙的是整天挂着 agent 的重度用户，这时候从 Pro 直接跳到 Max 5x 比在 Pro 上反复等重置更划算。

## 便宜之外，还要看的四件事

价格只是决策的一部分。这类第三方代订服务的风险点相对明确，值得在下单前逐条过一遍。

### 1. 退款和封号条款

这是最容易被忽略的一条。社区里有用户记录过平台此前的暂停服务经历，以及早做虚拟卡业务时期余额受影响的情况。关于封号，公开讨论中提到的处理方式是：如果官方退款，平台退剩余部分扣除少量服务费；**如果官方不退，平台通常不承担**。也就是说，因账号本身环境问题导致的封号，风险落在用户这边。

下单前把当前的退款政策看清楚，别只看价格。

### 2. 续费不是自动的

按固定月数生效，到期不自动续，需要自己手动操作。对担心「忘了取消被扣钱」的人来说这是好事，但反过来也意味着：到期那天忘了续，你的 Claude Code 会在任务做到一半时停下来。

### 3. Session 凭证的授权边界

不需要密码这件事降低了风险，但不等于没风险。凭证本质上是登录态，能做的事和登录差不多。建议只在自己的主力账号上用，别在多个平台重复提交同一份凭证。

### 4. 账号归属始终是你

相比共享号、成品号，代订模式最大的实际好处是账号还是你的——聊天记录、Projects、订阅状态都在自己的账号里，不用中途换号重来。这一点对 Claude Code 尤其重要，因为本地还挂着配置文件和历史会话。
